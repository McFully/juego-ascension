# Guía de Prompts Musicales para Ascensión (Google Flow Music)

Documento de prompts para la generación de la banda sonora instrumental del juego de estrategia espacial **Ascensión** utilizando Google Flow Music.

Cada sección contiene:
- **Pantalla / Contexto** a la que corresponde.
- **Nombre de archivo sugerido** (formato `.ogg` / `.mp3` estandarizado para el runtime).
- **Bloque de código listo para copiar y pegar** con el prompt instrumental optimizado (en inglés, ya que Google Flow Music e IAs generativas de audio rinden al máximo en dicho idioma).

---
