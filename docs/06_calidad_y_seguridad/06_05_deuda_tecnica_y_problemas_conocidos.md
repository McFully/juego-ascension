# DEUDA TÉCNICA Y PROBLEMAS CONOCIDOS

## 1. PUNTOS DE AUDITORÍA Y COMPATIBILIDAD
- **Migración de Saves v1/v2:** Los saves muy antiguos requieren normalización de campos para asignar nuevos atributos de gobernanza ministerial y naves personalizadas.
- **Carga de Audio en Chromium:** Las políticas de reproducción automática requieren interacción previa del usuario (click) antes de iniciar la música ambiental (`Musica-menu.ogg`).
- **Sincronización de Versiones en Scripts de Build:** Garantizar que el script de empaquetado mantenga consistencia entre `package.json`, el ejecutable final y la referencia en la landing page.
