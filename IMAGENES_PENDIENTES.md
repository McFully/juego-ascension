# Catálogo de Imágenes Pendientes para Ascensión (Prompts Listos para Copiar)

> **Instrucciones para Google Gemini**:
> 1. Copia el bloque de código de cada prompt con un solo clic.
> 2. Pégalo en Gemini / Imagen 3.
> 3. Descarga la imagen y guárdala con el **Nombre de Archivo** indicado dentro de la carpeta `Assets/`.
> 4. Formato recomendado: `.webp` en proporción `16:9` panorámico (o convertir desde `.png`).
> 5. Todos los prompts incorporan instrucciones explícitas para **cero texto, cero interfaz y cero marcas de agua**.
