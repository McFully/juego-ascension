# Persistencia Local Obligatoria

- TODA partida se guarda en disco local (`%APPDATA%/Ascension/`)
- TODA partida se carga desde disco local
- TODA importación/exportación es desde/a archivos locales `.json`
- PROHIBIDO: cloud saves, servidores externos, sincronización online
- Backup automático antes de sobrescribir save (`.bak`)
